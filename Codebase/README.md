Hotel Revenue Analyzer

Project Overview

Hotel Revenue Analyzer is a Python-based project designed to analyze hotel sales and revenue data.

Technologies Used

- Python
- Pandas
- Matplotlib

Project Files

- "main_project.py" – Main Python source code.
- "hotel_sales.csv" – Dataset containing hotel sales information.

Features

- Reads hotel sales data from a CSV file.
- Analyzes hotel revenue using Pandas.
- Displays data analysis and visualizations using Matplotlib.

How to Run

1. Install Python.
2. Install the required libraries:
   "pip install pandas matplotlib"
3. Run the program:
   "python main_project.py"
